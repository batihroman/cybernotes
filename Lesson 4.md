What commands I have learned and used today:
- nano> create and edit text
- VIM> an advanced, better redactor
- wget + link> download a file/program/etc from the web
- scp + source and destination> copy and transfer files from or to a remote machine
- python3 -m http.server> open a Python server (have to open a new terminal for typing commands
- ps> provide a list of the running processes in our user's session and some additional information, such as its status code
- ps aux> to see the processes run by other users and those that don't run from a session
- top> real-time statistics about the processes running on your system, instead of a one-time view
- kill> stop the program
- SIGTERM> kill the process, but allow it to do some cleanup tasks beforehand
- SIGKILL> kill the process, doesn't do any cleanup after the fact
- SIGSTOP> stop/suspend a process
- fg> is being used to bring the background process back into use on the terminal, where the output of the script is now returned to us
- systemctl + start/stop/enable/disable + service> allows us to interact with the **systemd** process/daemon
- cron/crontab> opens a tab where we can automate processes when the system boots
