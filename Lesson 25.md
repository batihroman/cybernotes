Section 6: Cryptography.
Lesson 1: Cryptography Basics.

- What is cryptography
Cryptography is used to protect information so only the intended person can read it. It helps keep data private, protects it from being changed, and helps verify that it came from the right source.

- Plaintext, ciphertext, and keys
Plaintext is the original readable message. Ciphertext is the encrypted version. A key is the secret value used to lock and unlock the message.

- Symmetric encryption
Symmetric encryption uses one key for both encryption and decryption. It is fast and good for large amounts of data, but the key has to be shared safely first.

- Asymmetric encryption
Asymmetric encryption uses two keys, a public key and a private key. The public key can be shared, but the private key stays secret. This solves the problem of sharing one secret key with another person.

- Caesar Cipher
The Caesar Cipher is a simple shift cipher. Each letter moves by a fixed number of places in the alphabet. It is easy to understand, but it is not secure.

- XOR and modulo
I learned two basic math operations used often in cryptography. XOR is useful because applying the same XOR key twice can restore the original value. Modulo gives the remainder after division and appears in many modern crypto systems.

- Summary
This room gave me the basic idea behind cryptography. I learned the difference between plaintext and ciphertext, how symmetric and asymmetric encryption work, why XOR and modulo matter, and why simple ciphers like Caesar are not secure.
