Day 15: Cybersecurity 101, WindowsCommand Line.

What I did today:
- A Windows Command Line room.
- Learned new commands.
- Practiced networks with new commands.

What I learned today:
- Why CLI is better in some ways than a GUI.
- Command "set" to check my path from the command line.
- Command "ver" to determine an operating system.
- Command "systeminfo" to list info about system such as OS info, System detailes, processor, memory.
- Adding "| more" to list info about the command.
- Command "ipconfig" to check my network info. This outputs IP, subnet mask, default gateaway.
- Adding "/all" to the "ipconfig" to list all the info about the network configuration.
- Command "....com ping" to check the ping from the website.
- Command "nslookup ....com" to look up a host or domain and recieve an IP address.\
- Addings "-a" displays all established connections and listening ports.
- "-b" shows the program associated with each listening port and established connection.
- "-o" reveals the process ID (PID) associated with the connection.
- "-n" uses a numerical form for addresses and port numbers. 
- Commands "cd", "dir", "cd..", "mkdir", "rmdir" for basic info, place, adding, deleting.
- Commands "type" or "more" to show text in the file.
- Commands "move", "copy", "del", "erase".
- Command "tasklist" to list the running processes.
- Command "tasklist /FI "imagename eq sshd.exe" " to search for tasks related to sshd.exe (example).
- Commands "shutdown /s" to shutdown the system and "shutdown /r" to restart it, and "shutdown /a" to schedule a system shutdown.
