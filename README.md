# Cybersecurity Study Log

Here is every lesson I covered, every command I ran, every concept that didn't click until it did while starting my cybersecurity education.

Started December 31, 2024. One session per day, following the TryHackMe Intro to Cyber Security path, and then transitioning into TryHackMe Cyber Security 101.

---

## How This Is Organized

Each lesson is a separate file. Early lessons are written as a journal — goal for the day, steps completed, key concepts, commands to practice. Later lessons follow the module structure of the TryHackMe path — numbered topics, technical specs, commands, and notes from the practical exercises.

Written during each session, not cleaned up afterward.
